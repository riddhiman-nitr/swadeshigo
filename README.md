🚀 Overview

SwadesiGo Growth OS is an interactive strategic platform designed around a Demand Before Dealership approach to EV market expansion.

Instead of committing significant resources to physical infrastructure before validating a market, the framework focuses on:

Demand Generation → Market Validation → Customer Intelligence → Data-Driven Expansion

The platform brings these components together into an interactive growth dashboard.

---

🎯 Core Strategy

Demand Before Dealership

The core idea is to validate local customer demand before making major dealership and infrastructure investments.

This approach helps create a structured pathway for entering new markets:

1. Identify potential markets
2. Generate local demand
3. Build an initial customer community
4. Collect real-world usage data
5. Measure market readiness
6. Scale infrastructure based on validated demand

---

🏆 100 Champions Program

The 100 Champions Program focuses on acquiring and activating the first 100 customers or EV advocates within a target market.

These early customers can help establish local demand while creating a foundation for organic growth.

Key objectives

- Generate early market demand
- Build local EV communities
- Encourage referral-led acquisition
- Create customer advocates
- Validate market potential
- Generate market-level insights

---

📡 RealRange Telematics

RealRange Telematics focuses on capturing real-world EV usage data to complement standardized vehicle specifications.

The framework can be used to understand:

- Real-world driving behaviour
- Range requirements
- Driving patterns
- Charging requirements
- Route characteristics
- Customer usage patterns
- Market-specific EV requirements

This data can subsequently support product positioning and expansion decisions.

---

📊 Growth OS

The Growth OS serves as the central layer connecting demand generation, customer acquisition, market intelligence, and expansion planning.

It provides a framework for tracking and interpreting:

- Market demand
- Customer acquisition
- Community growth
- Conversion
- Market validation
- Customer behaviour
- Expansion readiness

---

💡 Key Concept

The platform is built around a simple growth loop:

        MARKET IDENTIFICATION
                 ↓
        DEMAND GENERATION
                 ↓
        100 CHAMPIONS
                 ↓
        CUSTOMER DATA
                 ↓
        MARKET VALIDATION
                 ↓
        INFRASTRUCTURE
                 ↓
          MARKET SCALE
                 ↺

The objective is to make physical expansion a consequence of validated demand rather than the starting point.

⚙️ Getting Started

Prerequisites

Make sure you have Node.js and npm installed.

1. Clone the repository

git clone https://github.com/riddhiman-nitr/swadeshigo.git

2. Enter the project

cd swadeshigo

3. Install dependencies

npm install

4. Build the project

npm run build

The repository's build process generates the optimized CSS and JavaScript bundles and then runs the project build script.
